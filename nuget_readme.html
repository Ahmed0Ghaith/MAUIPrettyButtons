MauiAnimatedButtons

A collection of 8 beautifully animated, press-responsive controls for .NET MAUI — loading spinners, floating action buttons, ripple, pulse, morph and more. Drop-in ready with full MVVM support.

Button Showcase

LoadingButton
Controls/LoadingButton.cs
Spins a loader while IsLoading=true. Text fades, spinner fades in. Tap is auto-blocked.
FloatingActionButton
Controls/FloatingActionButton.cs
Material FAB — circle or extended — with bounce press and notification badge support.
RippleButton
Controls/ButtonCollection.cs
Press-ripple wave radiates from the tap point. Configurable color and opacity.
PulseButton
Controls/ButtonCollection.cs
Continuously pulses in a loop. Pause stops the animation. Perfect for CTAs.
ToggleButton
Controls/ButtonCollection.cs
Two-state with smooth color and text crossfade. TwoWay binding + Toggled event.
IconButton
Controls/ButtonCollection.cs
Icon-only in Ghost, Filled, or Outline style. Optional label below. Scale-bounce press.
MorphButton
Controls/ButtonCollection.cs
Morphs rectangle → circle on tap, shows success icon, then resets automatically.
OutlinedButton
Controls/ButtonCollection.cs
Ghost/outline style with configurable stroke color, thickness, and scale press.
Disabled State
AnimatedButtonBase.cs
Built into every button. Blocks tap, fades to 42% opacity, halts all animations. Bind IsEnabledButton.
02

Disabled & Enabled States

Every button inherits a built-in disabled state from AnimatedButtonBase. Setting IsEnabledButton=false will: block all tap/gesture events, animate opacity to 42%, halt continuous animations (pulse, spinner), and prevent Command execution — all automatically, with no extra code required.

✓ ENABLED IsEnabledButton = true
Tap events ✓ Active
Opacity 1.0 (100%)
Press animation ✓ Plays
Pulse / Spinner ✓ Running
Command.Execute ✓ Fired
Cursor pointer
✕ DISABLED IsEnabledButton = false
Tap events ✕ Blocked
Opacity 0.42 (42%)
Press animation ✕ Skipped
Pulse / Spinner ✕ Halted
Command.Execute ✕ Never called
Cursor not-allowed
Static disable / enable
XAML
MainPage.xamlxml 
<!-- Always disabled -->
<mab:LoadingButton
  Text="Submit"
  IsEnabledButton="False"
  ButtonBackgroundColor="#6C63FF" />

<!-- Always enabled (default) -->
<mab:LoadingButton
  Text="Submit"
  IsEnabledButton="True"
  ButtonBackgroundColor="#6C63FF" />
Bind to ViewModel
MVVM · TwoWay binding

Bind IsEnabledButton to any boolean property in your ViewModel. A negation converter is included.

MainPage.xamlxml 
<mab:LoadingButton
  Text="Pay Now"
  LoadingText="Processing..."
  IsLoading="{Binding IsBusy}"
  IsEnabledButton="{Binding CanSubmit}"
  Command="{Binding PayCommand}"
  ButtonBackgroundColor="#5b4cf5" />

<!-- Invert using built-in negation converter -->
<mab:RippleButton
  Text="Cancel"
  IsEnabledButton="{Binding IsBusy,
    Converter={StaticResource InvertBool}}" />
ViewModel.csC# 
public class CheckoutViewModel : ObservableObject
{
  [ObservableProperty]
  private bool _canSubmit = true;

  [ObservableProperty]
  private bool _isBusy;

  [RelayCommand(CanExecute = nameof(CanSubmit))]
  private async Task PayAsync()
  {
    IsBusy = true;
    CanSubmit = false;
    await ProcessPaymentAsync();
    IsBusy = false;
    CanSubmit = true;
  }
}
Code-behind toggle
C#
MainPage.xaml.csC# 
// Disable a specific button
myLoadingButton.IsEnabledButton = false;

// Re-enable it
myLoadingButton.IsEnabledButton = true;

// Disable during async work
private async void OnSubmit(object sender, EventArgs e)
{
  submitBtn.IsEnabledButton = false;
  await DoWorkAsync();
  submitBtn.IsEnabledButton = true;
}

Setup

1

Install the package

Add the NuGet package to your .NET MAUI project.

terminalbash
dotnet add package MauiPrettyButtons
2

Register in MauiProgram.cs

MauiProgram.csC#
using MauiPrettyButtons;
builder.UseMauiApp<App>().UseMauiPrettyButtons();
3

Add XMLNS to XAML pages

MainPage.xamlxml
xmlns:mab="http://MauiPrettyButtons.com/dotnet"
